# Voice Studio 사용법

[English](USAGE.md) · [컨버터 단계별 안내](../converter/USAGE.ko.md)

## 용도 고르기

APK 하나에 모든 기능이 들어 있습니다. Shizuku는 가상 마이크를 사용할 때만 필요한 선택 기능입니다.

| 하고 싶은 일 | 기능 | Shizuku | 백그라운드 동작 |
| --- | --- | --- | --- |
| 녹음이나 파일의 목소리 바꾸기 | 녹음 / 변환 | 불필요 | 변환 화면을 유지하세요 |
| 변환된 내 목소리 미리듣기 | 실시간 | 불필요 | 마이크 서비스와 알림으로 유지 |
| 앱 안의 웹사이트에 음성 보내기 | 실시간 → 웹 통화 | 불필요 | 웹 화면을 나가면 음성 전달 해제 |
| 설치된 다른 앱에 음성 보내기 | 실시간 → 가상 마이크 열기 | 실행 중이어야 함 | 상태 알림 표시, 입력이 없으면 대기 |

웹 통화는 실험적인 대안이며, Shizuku 없이 모든 설치 앱의 마이크를 바꾸는 기능은 아닙니다. 사이트 바로가기가 있다고 해당 사이트의 통화가 검증된 것은 아닙니다.

## 처음 준비하기

1. Voice Studio를 설치하고 한 번 엽니다.
2. **설정 → 받기**로 공통 모델 HuBERT와 RMVPE를 받습니다. 받기에 실패하면 PC 컨버터의 공통 모델 옵션 또는 `--common`으로 만들 수 있습니다.
3. [컨버터 안내](../converter/USAGE.ko.md)에 따라 RVC v2 · 48 kHz · 음높이(f0) `.pth`를 폰용 파일로 변환합니다. 폰 앱은 `.pth`를 직접 불러오지 않습니다.
4. 결과 ZIP/폴더를 **불러오기**로 넣거나 컨버터의 **폰으로 보내기**를 사용한 뒤 목소리를 선택합니다.
5. 변환 탭에서 음높이와 포먼트를 조정합니다. 설정은 모델별로 저장됩니다. 가상 마이크는 시작할 때 설정을 읽으므로 실행 중 바꿨다면 다시 시작하세요.
6. 녹음·실시간 기능을 사용할 때 마이크 권한을 허용합니다. 알림 권한도 허용해야 알림창에서 상태와 끄기 버튼을 볼 수 있습니다.

한국어 시스템에서는 한국어, 그 외에는 영어로 표시됩니다. Android 13 이상은 앱의 **설정 → 앱 언어**에서 시스템의 앱별 언어 선택 화면을 열 수 있습니다. 이전 Android에서는 시스템 언어를 따릅니다. 모델 이름과 기존 녹음 파일 이름은 유지합니다.

## 녹음·파일 변환

1. **녹음**에서 빨간 버튼을 누르고 말한 뒤 다시 눌러 멈춥니다.
2. **이 녹음 변환하기**를 누릅니다. 기존 파일을 쓸 때는 변환 탭에서 **파일 고르기**를 누릅니다.
3. 목소리와 음높이·포먼트를 고르고 **변환하기**를 누릅니다.
4. 원본과 결과를 비교합니다. **저장**하면 음악/VoiceStudio에 넣고, **공유**하면 Android 공유 창을 엽니다.

## 실시간 미리듣기

이어폰을 연결하고 목소리를 선택한 뒤 실시간 탭의 **켜기**를 누릅니다. 이 기능만 켜면 소리가 폰에서 재생되며 다른 앱의 입력을 바꾸지는 않습니다. 앱이나 알림의 **끄기**로 종료합니다. 실시간 녹음 버튼은 원본과 변환 결과를 녹음 탭에 저장합니다.

계산 장치 설정은 파일 변환과 이 실시간 모드에 적용됩니다. 사용할 수 없는 가속기는 CPU로 전환할 수 있습니다. 처리 시간이 블록 길이보다 길면 블록을 늘리거나 파일 변환을 사용하세요. 가상 마이크는 현재 S23+에서 검증한 별도 설정을 사용합니다.

## Shizuku 없이 웹 통화

1. **실시간** 변환을 켭니다. **변환 없이 통과**는 꺼둡니다.
2. **웹 통화**를 열고 사이트를 고르거나 HTTPS 주소를 입력합니다.
3. 사이트에 로그인합니다. 필요하면 **PC 화면 / 모바일 화면**을 바꿉니다.
4. 페이지의 **통화 오디오 준비**가 보이면 누른 뒤, 보라색 조작부의 **이 사이트에 변환 음성 연결**을 누릅니다.
5. 사이트에서 직접 통화나 음성 채널에 들어갑니다. 입력 장치를 고를 수 있으면 `Voice Studio · converted voice`를 선택합니다.
6. 상태 표시 옆 화살표로 조작부를 접거나 펼칩니다. **더 보기**에 뒤로·앞으로·새로고침·로그인 지우기가 있습니다.
7. **변환 음성 연결 해제**로 전달을 중지합니다. 웹 화면에서 나가기, 화면 잠금, 페이지 이동·새로고침도 전달을 해제합니다. 돌아오면 직접 다시 연결하세요. 변환 엔진까지 끄려면 실시간 탭이나 알림에서 끕니다.

이어폰을 사용하세요. 웹 음성이 연결된 동안 내 목소리의 로컬 재생은 꺼지고 연결을 끊으면 복구됩니다. 웹 입력에는 변환 음성 또는 무음을 보내며, 웹사이트가 실제 마이크·카메라를 직접 사용하는 요청은 거부합니다. 영상 촬영은 지원하지 않습니다. **로그인 지우기**는 현재 사이트 하나가 아니라 앱 안 브라우저의 모든 사이트 로그인 데이터를 지웁니다. 외부 브라우저 데이터는 지우지 않습니다.

사이트 로그인 제한·WebView·WebRTC 동작에 따라 호환성이 다릅니다. 연결 준비가 안 되면 Android System WebView를 업데이트하고 새로고침 → 통화 오디오 준비 → 음성 연결 순으로 다시 시도하세요. Shizuku로 확인한 네이티브 Discord와 웹 통화의 호환성은 별개이며, 이번 변경에서 웹 통화의 실제 상대 수신 음질은 확인하지 않았습니다.

## Shizuku로 가상 마이크 사용

### Shizuku 시작

[공식 사이트](https://shizuku.rikka.app/)에서 Shizuku를 설치합니다. 검증한 방식은 루팅 없는 무선 디버깅입니다. Android 11 이상에서는 Shizuku에서 페어링을 시작하고 **개발자 옵션 → 무선 디버깅 → 페어링 코드로 기기 페어링**에서 나온 6자리 코드를 Shizuku 알림에 입력합니다. Shizuku로 돌아가 **시작**을 누르고 실행 중인지 확인합니다. 재부팅 후에는 다시 시작해야 합니다. 기기별 절차는 [공식 설정 안내](https://shizuku.rikka.app/guide/setup/)를 참고하세요.

설치만으로 실행되지는 않습니다. 이 구현은 Android shell 사용자로 실행한 Shizuku가 필요하며 root 모드는 지원하지 않습니다.

### 가상 마이크 켜기

1. Voice Studio의 일반 실시간 변환과 녹음을 먼저 끕니다.
2. **실시간 → 가상 마이크 열기**를 누릅니다. Shizuku 상태 표시는 Shizuku를 열고, **사용 방법**은 앱 안의 설명을 엽니다.
3. 목소리를 선택하고 대상 앱 하나를 고르거나 **앱 입력 일괄 대체**를 켭니다.
4. **가상 마이크 켜기**를 누릅니다. Shizuku에서 Voice Studio를 승인하고 마이크·알림 권한도 허용합니다.
5. **마이크 입력을 기다려요**가 되면 대상 앱에서 녹음·마이크 테스트·통화를 시작합니다. 30초 안에 들어갈 필요가 없으며 5분 실행 제한도 없습니다.
6. **목소리를 보내고 있어요**로 바뀌는지 확인합니다. 알림은 준비·대기·소리 준비·변환 상태와 세션 경과 시간을 표시합니다. 펼치면 대상·모델·끄기가 보이고 본문을 누르면 앱으로 돌아갑니다.
7. 대상 앱이 마이크를 해제하면 캡처와 모델 계산을 쉽니다. 다음 입력이 생기면 이전 음성 문맥을 비우고 자동 재개합니다.
8. 앱이나 알림의 **끄기**로 종료하면 가상 입력 정책을 해제하고 원래 마이크로 돌아갑니다. 대상 앱의 통화 자체를 끝내지는 않습니다.

**일괄 모드:** 앱을 고르지 않고 지원되는 입력에 전달하며 Voice Studio와 원본 캡처용 shell 프로세스는 제외합니다. Android의 모든 입력 경로를 바꾼다는 보장은 아닙니다.

**앱 하나 선택 + 보안폴더 / 다른 공간:** 같은 패키지를 기본 공간에도 설치하고, 대상 앱과 다른 공간 옵션을 고릅니다. 해당 공간에서 마이크를 **먼저** 켠 뒤 가상 마이크를 시작해야 활성 입력으로 공간을 구분할 수 있습니다. 보안폴더는 직접 여세요. 앱이 그 안의 비공개 앱 목록을 읽지는 않습니다. 일괄 모드에서는 공간을 따로 선택할 필요가 없습니다.

**소리가 없거나 원래 목소리일 때:** Shizuku 실행·승인, 모델·대상 선택, 실제 마이크 입력 여부를 확인하세요. 가상 마이크 준비 후 대상 앱의 테스트 입력을 껐다 켜보세요. 통화의 음소거만으로는 입력이 해제되지 않을 수 있으므로 대기로 돌아가려면 테스트나 통화 입력 자체에서 나오세요. 입력·출력 미터와 처리 상태도 확인합니다. 권한을 거절했다면 Shizuku의 승인된 앱 또는 Android 앱 설정에서 허용하세요. 알림 안내를 누르면 알림 설정을 열 수 있습니다.

## 검증 범위

루팅 없는 Shizuku 경로는 Galaxy S23+ / Android 16에서 검사했습니다. 사용자 청취로 네이티브 Discord와 보안폴더 카카오톡의 변환 음성을 확인했고 일괄 모드에서 두 앱 전환도 확인했습니다. Instagram은 선택 가능하지만 청취 확인 전입니다. 일반 전화·블루투스 입력·다른 칩셋은 확인 전입니다.

상태 알림 검사에서 Discord 입력 약 146초 중 약 40초 동안 화면을 껐고, 화면을 켠 뒤에도 정상 음성을 확인했습니다. 입력 종료 시 캡처와 CPU 잠금이 해제됐고 알림의 끄기로 정책·서비스를 정리했습니다. 입력 건너뛰기와 AudioTrack underrun은 0회였지만 버퍼 회복 중 무음이 합계 220ms 있었습니다. 캡처→주입 약 653ms 추정에는 앱 버퍼와 통신 지연이 포함되지 않습니다. USB/ADB가 연결된 짧은 검사이며 배터리 단독 장시간 검사는 아닙니다.

변환은 폰 안에서 수행합니다. 대상 앱이나 웹사이트의 전송은 해당 서비스 동작을 따릅니다. 가상 마이크는 기본적으로 원본·변환 음성을 저장하지 않고 앱의 `virtual_mic/` 폴더에 크기가 제한된 처리 시간·진단 로그를 남깁니다. 사용자가 켠 녹음·내보내기는 별도입니다. Shizuku는 세션의 권한을 공급하며 앱에 시스템 권한을 영구 부여하지 않습니다.

웹사이트 쿠키와 로그인 세션은 설치된 앱의 비공개 브라우저 데이터에 남으며, 소스 코드나 빌드한 APK에는 포함되지 않습니다. 앱 업데이트는 이 데이터를 유지합니다. 지우려면 **웹 통화 → 더 보기 → 로그인 지우기**를 사용하세요.

통합판은 Android 단위 테스트 46개, 웹 브리지 테스트 25개, 한영 문자열 378쌍 검사를 통과했습니다. 폰에서 한국어·영어 조작부를 확인했고, 네이티브 Discord 청취 검사에서도 변환 음성을 다시 확인했습니다. 이 결과가 웹 통화의 실제 수신 호환성까지 검증한 것은 아닙니다.
